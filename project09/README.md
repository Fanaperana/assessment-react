# Project 09 — HabitLoop

Expo SDK 58 + React Native + Expo Router + TypeScript.

👉 **Read [ASSIGNMENT.md](ASSIGNMENT.md) first.** It has the requirements and the grading.

## Get started

```bash
npm install
npx expo start      # scan the QR code with Expo Go
```

## Checks (CI runs these on every pull request)

```bash
npm run typecheck
npm run lint
```

## Notes

- Install **Expo Go** on your phone, or use an Android emulator / iOS simulator.
- Add native modules with `npx expo install <package>` so versions match the SDK.
- Recommended Node.js version for all projects: **24 LTS**.

The starter was created with the official CLI. Everything else is your job. 💪
